# Material Designer

A Material Design 3 rebuild of a local-first design workspace.

The application source lives in `design/` and is a byte-for-byte copy of the
Apache-2.0 upstream release **Open Design v0.16.1**, imported verbatim and kept
that way so the copy can be *proved* against its source rather than asserted.
What this project adds on top is the Material Design 3 redesign, a rebrand that
makes the application genuinely standalone, and the feature set the project holds
itself to.

## Status

The application **builds, installs, launches and uninstalls cleanly** — proved by a
packaged smoke test that installs the built `.exe`, starts it, has the running
process answer its own health endpoint from inside its renderer, then removes it
and checks for residue.

The Material Design 3 token system is in. Still to come, tracked in `ROADMAP.md`:
the Cantonese locale, the funny-level sliders, the in-app regex builder, the dim
sum surprise and the changelog viewer. The site demonstrates all of them; the
application does not have them yet.
