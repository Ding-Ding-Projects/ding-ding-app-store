# Photo-Viewer Wiki

Welcome to the **Photo-Viewer** wiki! 📸

A **super advanced** photo & video viewer built with **React + TypeScript** and **Material Design 3 (M3 Expressive)** — with **persistent AI indexing** so your library is analyzed once, saved, and searchable forever. Self-host it in **one Docker container** and browse your library from **any device**, with **original-file downloads**.

> 🚧 **Status:** Planning stage — repository initialized, app scaffolding is next. See the [Roadmap](app-doc://article/photo-viewer.wiki.184cd41c0fa500ac).

## Feature Plan

- 📁 **Browse-for-folder** library picker — choose the photos/videos folder to index & view
- 🤖 **Persistent AI indexing** — objects, scenes, faces, OCR, colors; indexes saved locally and searchable later
- 🗂️ **Auto-organization** — sort & group by date, GPS location, media type; smart categories
- 🎬 **Video support** — playback, thumbnails, scrubbing; large videos split into **max 1 GB** parts
- 🗄️ **Local git-backed history** — the chosen photos folder is git-initialized with local snapshot commits
- 🐳 **Docker self-hosting** — one container, volume-mounted library, view & download originals on any device
- 🔍 **Search + regex builder** — unified search over indexes/metadata, full regex builder in every search bar
- 🎨 **M3 Expressive theming** — light/dark, density, seed color, fonts at runtime
- 🗣️ **Languages** — English / playful HK Cantonese / bilingual, per-language funny-level slider
