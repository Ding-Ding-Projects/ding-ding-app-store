# History features

- [Local version history](app-doc://article/material-download-manager.repository.3b8ccb0cce90c494) — isolated Git-backed
  snapshots, action/date/text filters, restore, diff, and export.
- [History browser panel](app-doc://article/material-download-manager.repository.fe8522105f3f9fd1) — the app tab that exposes
  filtered revision metadata and safe index exports without exposing snapshots.
- [In-app changelog viewer](app-doc://article/material-download-manager.repository.fec6cd5f38392e32) — embedded stable releases with
  local search, date filters, full source commit links, and filtered copy/export.
