# Navigation features

- [Tabbed navigation](app-doc://article/material-download-manager.repository.548bf1e0f6d6578c) — persistent tab state,
  pinning/grouping primitives, four searches, and protected bulk close.
- [Command palette](app-doc://article/material-download-manager.repository.4be3eb94f985536e) — `Ctrl+Shift+F` discovery with local
  plain-text and regex search.
- [In-app documentation browser](app-doc://article/material-download-manager.repository.c76dd8a6480ce39f)
  — the offline article tab and its local search/link contract.
