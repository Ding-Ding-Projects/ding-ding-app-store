# BambuStudio feature documentation

This directory documents the `Ding-Ding-Projects/BambuStudio` fork's maintained features and release
surfaces. Upstream Bambu Studio material remains in `../doc/`.

## Categories

- [Design system](app-doc://article/bambu-studio.repository.903bfdd22c351c0c) — vendored Material Design 3 token layer, the
  ground-up color/type/metric migration, and the parity audit.
- [GitHub Pages site](app-doc://article/bambu-studio.repository.aece644ce3be4e43) — the published tabbed site: navigation, language
  modes and funny levels, the shared regex builder, the changelog viewer, and the 444-case layout
  gate that guards its deploy.
- [Windows](app-doc://article/bambu-studio.repository.69ac012aacc766bc) — native MD3 UI, language modes, and visual verification.
- [Prepare](app-doc://article/bambu-studio.repository.ff12b808a24fe0a9) — Prepare-workspace features, including the dockable sidebar.
- [Model preview](app-doc://article/bambu-studio.repository.ffd1a335230db8b1) — the MakerWorld OpenGL preview shown before
  import.
- [G-code preview](app-doc://article/bambu-studio.repository.d11bf2f396b0633b) — the sliced Preview page: toolpath viewport,
  the color-scheme legend, and the layer/transport controls.
- [HTTP/API](app-doc://article/bambu-studio.repository.a88917a07ea8b9da) — short-lived, user-enabled network contracts, including the
  authenticated Home Assistant printer-discovery handover and its Postman collections.
- [Releases](app-doc://article/bambu-studio.repository.26ef528775b78eb0) — installer behavior, CI gates, SBOMs, attestations, and
  immutable-release policy.

The current delivery state and external dependencies are tracked in `../HANDOFF.md`.
Planned work is tracked in `../ROADMAP.md`.
