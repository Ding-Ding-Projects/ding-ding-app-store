# Browser-style navigation

| Feature | Contract | Status |
| --- | --- | --- |
| Tabs, pinning and grouping | [Tabs](app-doc://article/jdownloader-material.repository.2862082a3d69e74b) | Implemented |
| Four tab-discovery searches | [Tab discovery](app-doc://article/jdownloader-material.repository.4ea3723320c5d89e) | Implemented |
| Bulk close | [Bulk close](app-doc://article/jdownloader-material.repository.06763934f291dd82) | Implemented |

The navigation rail opens or focuses pages in a persistent browser-style workspace. Downloads,
LinkGrabber, History and Settings remain the primary rail destinations, while the New Tab menu also
opens Add Links, notifications, changelog and installed-JDownloader feature pages.
