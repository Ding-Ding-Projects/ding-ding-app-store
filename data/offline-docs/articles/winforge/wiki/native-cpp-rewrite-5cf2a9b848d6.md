# Native C++ Rewrite Moved · 原生 C++ 重寫已搬遷

WinForge is and remains the canonical **.NET 11 / WinUI 3** application. The experimental C++20/C++/WinRT rewrite is now an independent project at [codingmachineedge/WinForge-Native](https://github.com/codingmachineedge/WinForge-Native); it does not replace the managed app.

WinForge 而家同之後都以正式 **.NET 11 / WinUI 3** app 為主。實驗性 C++20／C++/WinRT 重寫已成為獨立項目，搬咗去 [codingmachineedge/WinForge-Native](https://github.com/codingmachineedge/WinForge-Native)，唔會取代受控 app。

Native source, dependency setup, build and smoke-test commands, parity evidence, screenshots, roadmap, handoff records, issues, and releases are maintained only in the native repository. Historical native instructions in this wiki are no longer authoritative.

原生 source、相依設定、build／smoke-test 指令、對等證據、截圖、roadmap、handoff 記錄、issues 同 releases 只會喺原生 repo 維護。呢個 wiki 以前嘅原生指引已經唔再係準則。

- [Native releases · 原生 releases](https://github.com/codingmachineedge/WinForge-Native/releases)
