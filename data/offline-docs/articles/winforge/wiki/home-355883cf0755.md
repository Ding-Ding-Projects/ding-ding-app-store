# WinForge · 視窗鑄造

WinForge is the canonical, fully bilingual (English + 粵語) **.NET 11 / WinUI 3** desktop control centre for Windows 11, with **319 registered in-app entries** and **1,214 total features** across 22 tweak categories and rich task modules.

**粵語 —** WinForge 係正式、全程雙語（英文 + 粵語）嘅 **.NET 11 / WinUI 3** Windows 11 桌面控制中心，有 **319 個已登記 app 內入口**同 **1,214 項總功能**，涵蓋 22 個調校分類同豐富 task modules。

## What is WinForge · 乜嘢係 WinForge

WinForge began life as a Windows 11 tweaker and grew into a full **convenience suite**: one shell now indexes 319 registered entries and 1,214 features. The whole app is bilingual *by design* — English, Cantonese, and bilingual modes are built into the UI. A master search spans the tweak catalog and every module page, so anything in the suite is one search away.

- **Real, reversible system changes** — registry, power plans, Winsock/TCP-IP reset, privacy/telemetry, cleanup, security
- **Two layers in one app** — a structured **tweak catalog** (22 categories) and 318 registered **task modules** plus Dashboard
- **Bilingual everywhere** — English **and** 粵語 on every card, title and description
- **Searchable** — a master search that indexes tweaks *and* module pages by keyword (EN + 粵語)
- **Honest badges** — admin / restart / sign-out indicators where an action needs elevation or a reboot

> **Safety · 安全** — WinForge writes **real** Windows settings. Most tweaks are reversible (toggle them back), but some need **administrator rights** or a **restart / sign-out** to take effect, and a few (cleanup, debloat, security) are destructive. Read each card's description before applying. See [FAQ-and-Safety](app-doc://article/winforge.wiki.677bfeab3d50421e).

## Why bilingual · 點解雙語

Language in WinForge is never hidden behind a menu. **Both** English and Cantonese (粵語) appear on every card at the same time — title *and* description — and the master search indexes both languages' keywords, so 「電池」 finds the same module as "battery". The Settings page only chooses which language *leads*; the whole UI updates live. See [Bilingual-Design](app-doc://article/winforge.wiki.4bf6df69605a148a) for how `LocalizedText` makes this work.
