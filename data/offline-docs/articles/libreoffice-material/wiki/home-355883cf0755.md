# LibreOffice Material wiki

LibreOffice Material is an experimental, Windows-only LibreOffice engineering
fork exploring a native Material Design 3 interface. The repository README and
categorized documentation remain the canonical technical record:

- [Project status and downloads](https://github.com/Ding-Ding-Projects/libreoffice-material#readme)
- Roadmap
- Release-channel integrity
- Windows-only build scope

## Verification boundaries

The complete local build-free fleet passed 171/171 commands with no Python
warnings. That proves source contracts and regressions, not end-user runtime.
MSI install/repair/upgrade/uninstall, updater interaction, and the open GUI-lag
measurement in [issue #12](https://github.com/Ding-Ding-Projects/libreoffice-material/issues/12)
still require real Windows runtime evidence.

Progress is tracked in [Discussion #27](https://github.com/Ding-Ding-Projects/libreoffice-material/discussions/27),
with the newest pushed changelog in [Announcement #30](https://github.com/Ding-Ding-Projects/libreoffice-material/discussions/30).
