# Transfers

Transfer features cover finding and managing torrents in the native Windows
desktop client.

- [Transfer-list filtering](app-doc://article/qbittorrent-material.repository.302b3350bd61beb9): select Name, Save path, Info hash v1,
  or Info hash v2 while retaining wildcard and regular-expression matching.
- [Peer contribution](app-doc://article/qbittorrent-material.repository.d8a88c59933c9ef5): inspect and sort the percentage of
  each peer's current progress supplied by this client.
- [Search runtime](app-doc://article/qbittorrent-material.repository.cf36f38a75ac4122): the bundled `nova3` Python runtime the
  Search tab drives, how its interpreter is resolved, and how each prerequisite
  failure is reported.
- [Transfer-list export](app-doc://article/qbittorrent-material.repository.09dda5565ab59c3b): scoped multi-format export, loss
  disclosures, escaping, sensitive fields, and verification.
