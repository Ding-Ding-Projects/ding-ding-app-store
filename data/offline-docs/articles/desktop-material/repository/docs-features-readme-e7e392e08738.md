# Desktop Material feature documentation

Feature documents are grouped by the part of the product that owns the
behavior. Each document covers the user workflow, persistence boundary,
failure modes, security considerations, and the checks expected before the
feature is described as accepted.

The [30-item GitHub Desktop demand backlog
ledger](github-desktop-demand-backlog.md) maps the supplied research brief to
the implemented feature contracts.

## Categories

- [Agent API](app-doc://article/desktop-material.repository.a8a8b30ccefce2b9) — opt-in REST and MCP automation,
  authentication, transport boundaries, and executable Postman requests.
- [Repository management](app-doc://article/desktop-material.repository.81d1704a64218393) — opening,
  organizing, and safely navigating repositories and nested repositories.
- [Integrations](app-doc://article/desktop-material.repository.551cace69da097e1) — user-level Git, editor, shell,
  operating-system connections, a sandboxed app-hosted browser, and
  repository-bound provider packages.
- [Identity and workspace](app-doc://article/desktop-material.repository.e904e2efd8da5f1a) — multiple
  accounts plus fast repository and branch navigation at workspace scale,
  including scheduled language and appearance values.
- [Collaboration](app-doc://article/desktop-material.repository.3e87fcf440334ec6) — pull-request review, creation,
  activity, and other provider-backed teamwork.
- [Review and diff](app-doc://article/desktop-material.repository.840bbd9307b1ae3f) — changed-file navigation and
  safe text, structured-data, and image inspection.
- [Quality and reliability](app-doc://article/desktop-material.repository.d123003c7eccf984) — cross-cutting
  responsiveness, lifecycle cleanup, failure recovery, and regression gates.
- [Design system](app-doc://article/desktop-material.repository.903bfdd22c351c0c) — Material presentation controls,
  including command-palette row appearance and responsive visual behavior.
- [Historical Linux TUI prototype](app-doc://article/desktop-material.repository.15fc41b41822766b) — archived July 27
  mouse/keyboard, package, XDG, RE2, security, parity, and acceptance records;
  not a supported product edition or Windows-release blocker.
