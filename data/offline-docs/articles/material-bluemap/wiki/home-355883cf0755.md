# Worldlens

The project documentation is published at the [Material 3 site](https://ding-ding-projects.github.io/worldlens/).

## Pages surface

The site uses a browser-style tab shell with repository-backed changelog entries, command
palette navigation, responsive documentation, per-element appearance editing, dynamic tab-group
discovery searches, searchable tab, group, overflow, and page-action menus, and a render-console
article reachable from the landing page. Every search field keeps plain text as the default and
exposes its own anchored regex builder. Clearing notification history, closing pages, removing a
group, and both bulk-close directions use the site's two-key super-confirmation gate.

Left and right navigation now have an accessible collapse control. A compact first visit starts
collapsed without hiding the expand target, an explicit visitor choice persists, and switching to
top or bottom keeps the complete horizontal strip. The tested hand-written inventory covers 41
shared user-facing requirements and records explicit browser-only boundaries instead of silently
dropping them. See [GitHub Pages feature parity](app-doc://article/material-bluemap.wiki.a0c52efa5e565060).

Settings also has a guided **Schedules** tab for versioned language and appearance rules. Rules can
use local date/time/weekday windows, a bounded JSON API, or a Home Assistant boolean entity. The
Home Assistant token lives only in page-session memory; `off` falls through to the next matching
rule. Every docked panel and transient popover/menu shares persisted, viewport-bounded resize
controls; transient surfaces drag and all have keyboard and reset paths.

The source-level verification boundary is documented in the repository's
[design/HANDOFF.md](https://github.com/Ding-Ding-Projects/worldlens/blob/main/design/HANDOFF.md)
and [design/ROADMAP.md](https://github.com/Ding-Ding-Projects/worldlens/blob/main/design/ROADMAP.md).
