## Rewrite gap ledger · Rewrite gap 清單

The refreshed shared requirements are recorded in the repository's
global-memory gap audit.
The packaged preview now covers the first runtime vertical slice — Mail, Settings,
searchable/date-filtered Changelog, local append-only History, Notifications, Tools,
and independent anchored bilingual regex builders. The Tools page now includes
a searchable 14-entry design-folder feature guide, and each guide result now opens
a localized five-section article details surface. Notifications now also have
local search, retained dismissal, and all/unread/dismissed filters; a catalog-backed
dim-sum draw, anchored appearance-editor with continuous local colour translation,
fact-preserving funny-level copy for preview surfaces/exports, and serialized narrator
foundations are documented as partial.
The open runtime families are:

- Material landing/documentation page covering every feature.
- English, playful Hong Kong Cantonese, and compact bilingual modes.
- Independent English/Cantonese funny-level sliders from 1 to 5 (preview copy wired; app-wide event/error coverage open).
- Non-blocking notifications and history centre.
- Local dim-sum startup surprise and release code-name display.
- Full anchored regex builder for every search bar.
- Per-element appearance editor, mounted continuous color translator, Word-depth typography, and every-element coverage.
- Browser tabs with overflow, pinning, grouping, four searches, and safe bulk-close preview.
- External editor integration, local Git-backed record history, and all-release changelog viewer.
- Optional serialized English/Cantonese narrator.

呢啲唔係得個 checklist 名；每一項都要有 real runtime surface、測試、文件同真實
capture 先可以叫完成。紫色外套已經出街，成套 Material 衫仲喺度裁剪緊。
