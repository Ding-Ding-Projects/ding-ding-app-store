# Static documentation site foundation

Open `index.html` from a local static server (or any static host). It has no CDN, analytics, remote fonts, remote scripts, or remote images. The site uses only `index.html`, `assets/app.css`, and `assets/app.js`.

## Included foundation

- Material Design 3-inspired local tokens, surfaces, typography, elevation, and motion.
- Complete feature inventory with detailed in-site articles and related-article suggestions.
- Plain-text-first documentation search with an adjacent regex builder, flags, sample text, validation, match preview, and bounded input lengths.
- English, Hong Kong Cantonese, and bilingual modes plus independently persisted English/Cantonese funny-level sliders.
- Persistent left-side documentation tabs, current article state, honest status/empty states, and keyboard navigation.
- `Ctrl+Shift+F` command palette for articles and settings, with direct article focus.

This is a source foundation, not a published Day Teet Hui deployment or a verified desktop runtime capture.
