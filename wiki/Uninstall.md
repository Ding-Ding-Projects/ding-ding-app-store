# Uninstall

Uninstall identifies the exact app, version, location, and ownership before removal, separates data handling where supported, and records the result in local history.

- Configuration: keep/remove data only when supported; native destructive confirmation.
- Failure: missing uninstaller, locked files, partial removal, cancellation, or unknown ownership remains visible.
- Security: canonicalized owned paths only; no arbitrary deletion.
- Verification: no destructive operation was run for this docs lane.

Detailed source: `docs/features/uninstall.md`.
