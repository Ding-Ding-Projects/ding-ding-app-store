# One-click installation

Install, Reinstall, and Install from source dispatch immediately from each catalog card. Only destructive uninstall/deletion keeps the two-key plus full-slider super-confirmation.

- Configuration: the renderer sends only a catalog application ID and closed decision; per-app adapters own commands, dependencies, paths, URLs, and arguments.
- Failure: missing adapters, ambiguous assets, integrity failures, timeouts, unsupported packages, and unavailable source sandboxes fail honestly without guessed commands.
- Security: packaged routes retain HTTPS allowlists, size and SHA-256 checks, hidden shell-free execution, and cleanup. Future source routes require a structured terminal simulator plus pinned, bounded OpenCode bootstrap/repair only inside a disposable workspace with no arbitrary user paths or user secrets.
- Coverage: all 24 catalog records are listed in `docs/features/one-click-installation.md`; clean-Windows adapter and runtime proof remains incomplete for every record.

Detailed source: `docs/features/one-click-installation.md`.
